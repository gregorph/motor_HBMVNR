# Pharmacological simulations: `fig3.m`

This script examines basal-ganglia responses and motor behaviour under control, parkinsonian and pharmacological parameter profiles. It comprises a parameter sweep (`%% part 1`), repeated motor simulations (`%% part 2`) and figure assembly (`%% ploting`).

## Dependencies

Use the software environment described in the [main README](README.md). The model and plotting functions are:

| Function | Role |
| --- | --- |
| `basal_ganglia_fcn_pts` | Basal-ganglia response |
| `M1_fcn_pts` | Thalamocortical activity |
| `hbm_vnr` | Cerebellar activity |
| `spinal_circuits_fcn_pts` | Spinal and muscle outputs |
| `put_in_range` | Bounds model inputs |
| `plotEllipse` | Covariance ellipses for the scatter panels |
| MATLAB `violinplot` | Distribution plots |

The pharmacology model uses the `*_pts` functions listed above; the `*_pts_rtl` functions belong to a different model interface.

## Generate new simulations

Open `fig3.m` in the MATLAB Editor and execute the main blocks in order:

1. Run the complete `%% part 1` block, stopping before `%% part 2`.
2. Run the complete `%% part 2` block, stopping before `%% ploting`.
3. Save the simulation workspace:

   ```matlab
   save('fig3_simulation.mat', '-v7.3');
   ```

The first block clears the workspace. Internal section labels such as `%% BG` and `%% Cerebellum` occur inside loops; execute the complete parent block rather than an individual internal section.

## Basal-ganglia sweep

Part 1 evaluates 121 baseline dopamine values (`0:0.025:3`) and 79 motor-drive values (`0.01:0.005:0.4`) using 10,000 BG circuits per function call.

| Condition | Dopamine multiplier | Dopamine addition | ACh multiplier | `glutamine_mod` | `stn_gpi_w` |
| --- | --- | --- | --- | --- | --- |
| Healthy / Control | 1 | 0 | 1 | 0.5 | 1 |
| PD | 0.5 | 0 | 1 | 0.5 | 1 |
| Levodopa | 0.5 | 0.35 | 1 | 0.5 | 1 |
| High-dose levodopa | 0.5 | 0.65 | 1 | 0.5 | 1 |
| Anticholinergic | 0.5 | 0 | 0.6 | 0.5 | 1 |
| Amantadine | 0.5 | 0 | 1 | 0.25 | 0.5 |

The dopamine input is the baseline value multiplied by the condition-specific multiplier, plus the addition. The ACh input is twice the ACh multiplier. The horizontal plotting coordinate is `dopamine_levels/2`; the vertical coordinate is `motor_drive*250`.

The output `condition_checked(k).gpi_dp` has dopamine × motor-drive layout and contains GPi firing probability multiplied by 250.

## Repeated motor simulations

Part 2 uses five conditions, ordered Healthy, PD, Levodopa, Anticholinergic and Amantadine. It does not include the high-dose levodopa group. Each condition is simulated 48 times for 1,500 steps at 250 Hz, giving 6 s per realisation and 240 simulations in total.

The thalamocortical module uses 1,000 circuits; each BG call uses 10 circuits. Programme 1 has drive 0.4 throughout. Programme 2 is simulated throughout, with drive zero initially and 0.1 from approximately 3 s. Programme 1's target is `0.5 + 0.2*sin(2*pi*0.1*t)`; programme 2 uses amplitude 0.15 and a quarter-cycle phase offset.

Part 2 has its own parameter profiles: the PD dopamine multiplier is 0.4 and the levodopa addition is 0.3. These differ from the values in the BG sweep.

## Outputs

| Variable | Layout / meaning |
| --- | --- |
| `fig3b_velocity` | Condition × realisation × sample; signed per-step motor output |
| `fig3b_error_observed` | Condition × realisation × sample; desired minus achieved position |
| `fig3b_thalamus_net` | Thalamic flexor minus extensor activity |
| `fig3b_thalamus_summative` | Summed thalamic activity |
| `power_motor_tremor1_fig3`, `power_motor_tremor2_fig3` | First/second-half joint-position wavelet magnitude measures |
| `power_thalamustremor2_fig3`, `power_thalamusbeta2_fig3` | Second-half thalamic wavelet magnitude measures |
| `correlation_keep` | Target-position covariance |
| `corr_thalamus_error` | Thalamus/error correlation |
| `lag_keep` | Thalamus/error cross-correlation lag, in samples |

Time-series arrays have dimensions 5 × 48 × 1500. Multiply the per-step motor output by 250 to express it per second. Arrays named `power_*` in this script are calculated from `abs(CWT)`; they represent wavelet magnitude rather than squared power.

## Generate and export the figure

For a freshly generated workspace, execute the plotting body beginning with `num_circuits_bg = 1000;` immediately after the archived-data `load(...)` statement under `%% ploting`, through the end of the file. This uses the variables generated by Parts 1 and 2.

The composite figure contains BG response maps, tremor/velocity and covariance/error scatter panels, and distributions of thalamic spectral ratios, correlation and latency. `plotEllipse` draws covariance-scaled ellipses around the scatter groups.

Save the raw simulation workspace before plotting: the plotting block forms normalised tremor measures, clips negative thalamus/error correlations to zero, and displays absolute latency in seconds.

With the composite figure current:

```matlab
savefig(gcf, 'fig3_pharmacology.fig');
print(gcf, 'fig3_pharmacology.png', '-dpng', '-r300');
```

## Statistical analysis and reproducibility

`extract_pharmacological_stats.m` analyses the distribution data in a generated FIG file. Set its `filename1` to `fullfile(pwd,'fig3_pharmacology.fig')` and use the [statistical analysis guide](README_statistics.md). The analysis concerns the displayed distributions and their transformations.

Retain the raw simulation workspace, exported figure, parameter settings and source files together. The parallel repeats use worker random streams without an explicit saved seed/substream per realisation; archive the generated data for exact subsequent replotting and analysis.
